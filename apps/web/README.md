# apps/web — Next.js Frontend

Operator-facing web application: dashboards, reservation calendar, rates,
housekeeping boards, billing, and AI insights.

- Framework: Next.js (TypeScript, App Router)
- Consumes: `apps/api` via a typed client generated from its OpenAPI schema
- Uses shared packages: `packages/ui`, `packages/types`, `packages/config`
